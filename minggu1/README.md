## Week 1 — Personal Portfolio
A simple personal portfolio website showcasing my background, skills, and projects as a Cyber Security student.

### Pages
* `index.html` — Home page with introduction, about me, skills, and contact link
* `portfolio.html` — Portfolio page with project information and repository links
* `contact.html` — Contact page with social links and contact form

### Tech Stack
* HTML5
* CSS3
* Google Fonts

### Project Structure
```text
.
├── index.html
├── portfolio.html
├── contact.html
├── style.css
├── contact.js
└── assets/
    └── profile.png
```

## Getting Started
No build tools or dependencies are required.
1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the website using Live Server or open `index.html` in a browser.
